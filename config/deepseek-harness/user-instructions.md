# 用户级全局指令

本文件由 `config/deepseek-harness/AGENTS.md` 安装到 `$DSH_HOME/AGENTS.md`，是 DeepSeek
Harness 的**用户级**指令：它在所有项目指令**之前**注入，因此优先级**最低**——项目自己的
`AGENTS.md` 永远覆盖它，system/developer/用户直指令覆盖两者。

只写跨项目通用的内容。与某个仓库相关的规则写进那个仓库的 `AGENTS.md`，不要写在这里。

## 通用约定

- 不把明文机密（API key、token、密码、私钥）写入仓库、补丁文件、终端输出、截图或提交信息。
- 需要写入文件的配置变更，优先改配置来源而不是改生成结果；生成物只用于验证。
- 汇报结论时区分三类证据：静态检查通过、部署完成、业务功能验证通过。三者不能互相替代。

## 待补充

以下内容需要你按自己的偏好填写，当前故意留空，以免把猜测写进全局提示：

- 期望的回答语言与风格。
- 常用的工具与命令习惯（例如是否优先使用某个包管理器或构建工具）。
- 跨项目的代码风格偏好。
